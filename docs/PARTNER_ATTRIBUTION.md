# Partner attribution

ForgeGuard references and integrates with the following partners. Use of names and badges should respect each vendor's brand guidelines.

| Partner | Usage in ForgeGuard |
|---------|---------------------|
| [InsForge](https://insforge.dev) | Backend, audit store, executor; "Made with InsForge" badge in README |
| [Replicas](https://tryreplicas.com/) | Webhook enrichment (`replica_id`, `pr_urls`) |
| [Limrun](https://lim.run/) | Mobile preview URLs for pending ops |
| [Memoir](https://www.trymemoir.ai/) | Optional outbound webhook events |
| OpenRouter / model gateways | Optional LLM classifier and injection scan |

Confirm badge and name usage with each vendor before major marketing campaigns.
