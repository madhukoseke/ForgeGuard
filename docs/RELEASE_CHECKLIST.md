# Release checklist

Use this before tagging `v*` and publishing to npm.

## Pre-release

- [ ] All items in [OPEN_SOURCE_READINESS_CHECKLIST.md](./OPEN_SOURCE_READINESS_CHECKLIST.md) P0 are complete
- [ ] [CHANGELOG.md](../CHANGELOG.md) has a dated section for the release version
- [ ] `package.json` version matches the tag (e.g. `0.3.0` → `v0.3.0`)
- [ ] Run one-time history secret scan: `./scripts/secret-scan.sh`
- [ ] Rotate any keys that were ever present locally before the repo went public

## Local gates

```bash
npm run precommit
npm_config_cache=/tmp/forgeguard-npm-cache npm run pack:check
./scripts/pack-install-smoke.sh
npm audit --omit=dev
```

With InsForge credentials:

```bash
npm run bootstrap:insforge
npm run integration:insforge
```

## Publish

1. Commit version bump and CHANGELOG
2. Tag: `git tag v0.3.0 && git push origin v0.3.0`
3. GitHub Release — copy CHANGELOG section; attach SBOM if generated by CI
4. npm: `npm publish --provenance` (requires npm 2FA and `NPM_TOKEN` in CI)

## Post-release

- [ ] Verify `npx forgeguard-mcp --help` from the published tarball
- [ ] Update README badges (CI, npm version) if applicable
- [ ] Announce using [ANNOUNCEMENT.md](./ANNOUNCEMENT.md) template
